# PowerCalc. Спецификация формата документа v1

## 0. Принципы
- `document.txt` — UTF-8. Редактор сохраняет исходник байт-в-байт, без переформатирования.
- Блоки: YAML, заголовок, формула, текст; пустые строки разделяют блоки.

## 1. YAML-блок
- `---` … `---`, только первым блоком.
- Отступы: только 2 пробела. Таб в отступах → E001 с номером строки. Парсинг — yaml-cpp (свой YAML не пишем).
- Ключи v1: `title`, `author`, `date` (строки); `show_substitution` (bool, default true);
  `page.size` (default A4); `page.margin.top/bottom/left/right` (default 2cm, единицы cm|mm, короткой формы `margin:` нет);
  `align` (top-level: left|center|right|justify, default justify); `text.size` (default 14pt).
- Шрифт зашит: Times New Roman, в v1 не настраивается.
- Неизвестные ключи (включая `base_voltage`) игнорируются, но сохраняются при пересохранении.

## 2. Блоки
- Заголовок: `#`/`##`/`###` + пробел, ≤3 уровней; `#` без пробела — текст.
- Текст: всё остальное; `#` вне блока формулы — не комментарий.

## 3. Блок формулы
$$[модификатор]
<LaTeX-формула> [&единица]
[# комментарий]
$$
- Модификаторы: `hide` (не рендерится, но парсится и попадает в SymbolTable), `!` (инверсия show_substitution), `hide!`. Неизвестный → E003.
- Незакрытый блок → E002.
- Единица: первый `&` в последней строке блока; всё после — единица (любой текст, кириллица включительно), в вычислениях не участвует.
- Комментарий: `#` в начале строки внутри блока; в рендере не виден.
- Строки формулы (кроме модификатора и комментариев) склеиваются в одно выражение.
- Формула обязана быть присваиванием: слева переменная, иначе E010.

## 4. Переменные
- Имя: буква (лат/кириллица), далее буквы/цифры; `_` не входит в имя.
- Индекс: `_x` (один символ) или `_{...}` (до `}`); вложенность `_{a_{b}}` в v1 не поддерживается
  (в выражении → W001, слева присваивания → E010).
- Нормализация: `R_x` ≡ `R_{x}`, полное имя = `имя_{индекс}`.
- LaTeX: `\sqrt \frac \sin \cos \tan \log \ln \exp \abs` — функции; `\pi`, `e` — константы; `j` — мнимая единица;
  `\cdot`, `\times` — умножение; `\pm` — в v1 не вычисляется (W001); греческие `\alpha`… — переменные `alpha`….
- `\ln` — натуральный логарифм, `\log` — десятичный.
- Неявное умножение поддерживается (`2x`, `jQ`, `(a)(b)`).
- Зарезервированные имена (`sqrt`, `frac`, `sin`, `cos`, `tan`, `log`, `ln`, `exp`, `abs`, `pi`, `e`, `j`) нельзя определять → E007.

## 5. Вычисление
- Значения — комплексные; действительные = Im 0.
- Строго в порядке появления в документе (формулы и inline-ссылки). Ссылка на неопределённую → E005. Цикл → E005 (E004 в v1 не используется).
- Переопределение разрешено, побеждает последнее.
- Невычислимо (деление на ноль, неизвестная команда `\int` и т.п.) → W001: значение не вычисляется, подстановка пропускается, документ не блокируется. E006 в v1 не используется (LaTeX валидирует KaTeX в 2.3).

## 6. Inline-формулы
- `$$имя$$` в тексте → значение переменной на момент встречи. Не определена → E005 с номером строки.

## 7. Ошибки
- Парсер собирает все ошибки. Диагностикa: код, строка (1-based), текст.
- Коды v1: E001, E002, E003, E005, E007, E010, W001.

## 8. Производительность
- 1000 строк < 100 мс; 10000 строк < 1 с.
