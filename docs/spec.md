# Спецификация формата документа PowerCalc

**Версия:** 1.3
**Статус:** Финальная для v1 продукта

## 1. Обзор

Документ PowerCalc — текстовый файл `document.txt` (UTF-8) внутри ZIP-проекта.
Markdown-подобный синтаксис с блоками формул. Формулы вычисляются в порядке
появления, значения подставляются при рендере. Рендер — KaTeX; парсер/эвалюатор
от рендера не зависят. Экспорт — HTML и PDF (нумерация страниц в PDF — через qpdf).

## 2. Блоки

| Тип | Синтаксис |
|-----|-----------|
| YAML | `---` … `---`, только первым блоком |
| Заголовок | `#` / `##` / `###` + пробел |
| Формула | `$$` … `$$` |
| Таблица | строки `\| … \| … \|` |
| Список | `- ` / `1. ` |
| Картинка | `![подпись](файл)` |
| Оглавление | `[toc]` |
| Разрыв страницы | `[break]` / `[pagebreak]` |
| Текст | всё остальное; пустые строки разделяют блоки |

## 3. YAML блок

- Парсится yaml-cpp. Отступы — 2 пробела на уровень; таб в отступах → E001.
- Ключи v1.3:

| Ключ | Тип | Дефолт |
|------|-----|--------|
| `title` / `author` / `date` | string | пусто |
| `show_substitution` | bool | `true` |
| `align` | left/center/right/justify | `justify` |
| `heading_align` | left/center/right/justify | значение `align` |
| `page.size` | A4/A3/A5/Letter | `A4` |
| `page.margin.top/bottom/left/right` | length (cm/mm) | `2cm` |
| `text.size` | length (pt) | `14pt` |
| `toc_size` | length (pt) | размер текста |
| `show_page_numbers` | bool | `true` |
| `page_start` | int ≥ 1 | `1` |
| `number_first_page` | bool | `false` |

- Шрифт зашит: Times New Roman.
- Неизвестные ключи игнорируются и сохраняются при пересохранении.

## 4. Заголовки

`#`, `##`, `###` + обязательный пробел. `####` и более, `#` без пробела — текст.
Локальный стиль: `# Титл {center,12pt}` или `{align:center,size:12pt}`.

## 5. Блок формулы

### 5.1 Открытие и закрытие

- Открывается строкой, начинающейся с `$$`; далее опциональный модификатор,
  далее опционально контент на той же строке. Закрывается следующим `$$`
  (отдельная строка или хвост строки с контентом). Незакрытый блок → E002.
- Многострочный блок: модификатор может стоять либо на открывающей строке
  (`$$! …`), либо первым токеном первой контент-строки (`$$\n! u =\n$$`).
- Однострочные формы: `$$X$$`, где между скобками выражение **без пробелов** —
  inline в тексте (см. §8); с пробелами, `=` или модификатором — блок.
- После закрывающего `$$` текст — текст с inline; `{…}` — локальный стиль (5.6).

### 5.2 Модификаторы (семантика v1.3)

| Модификатор | Значение |
|-------------|----------|
| (нет) | формула вычисляется |
| `hide` | не рендерится, но вычисляется и определяет переменные |
| `!` | чистый LaTeX: рисуется как написано, не вычисляется, не определяет |
| `hide!` | скрыт и не вычисляется |

`!` пишется слитно или с пробелом (`!u`, `! u`). Слово без модификатора —
не ошибка: это выражение (E003 более не генерируется).

### 5.3 Единица измерения

Первый `&` в последней контент-строке; всё после — единица (любой текст).
В вычислениях не участвует. Работает и в inline (5.8/§8).

### 5.4 Комментарии

Внутри блока `#` — комментарий до конца строки или до `$$`, в т.ч. в середине
строки. Не рендерится. Вне блока `#` — заголовок/текст.

### 5.5 Склейка

Контент-строки (кроме комментариев) соединяются через пробел в одно выражение.

### 5.6 Локальные стили

После закрывающего `$$`: `{align:…, size:…, show_substitution:true/false}` —
по отдельности или через запятую; для заголовков/текста/списков допустима
короткая форма `{center,12pt}`. Переопределяют YAML на один блок.

## 6. Переменные, индексы, имена

- Имя: буква (лат/кириллица), далее буквы/цифры.
- Индекс: `_x` или `_{...}`; `R_x` ≡ `R_{x}`. Вложенные → W001.
- Зарезервированы (определение → E007): `sqrt frac sin cos tan log ln exp abs pi e j`.
- Греческие `\alpha`… — переменные `alpha`…; `\cdot`, `\times` — умножение; `\pm` → W001.
- `\log` — десятичный, `\ln` — натуральный.

## 7. Выражения и вычисление

- Формула — присваивание (`x = …`) **или голое выражение** (v1.3): голое —
  вычисляется, значение подставляется, переменная не определяется.
  E010 более не генерируется.
- Пустая правая часть (`u =`) → W001; при рендере подставляется текущее значение.
- Вычисление в порядке появления. Неопределённая переменная → E005.
- Переопределение разрешено, побеждает последнее.
- Ошибка вычисления → переменная не определяется; старое значение живёт.
- Операции `+ - * ^ /`, скобки, числа с `.`, `j`, `pi`, `e`; функции
  `\sqrt \frac \sin \cos \tan \log \ln \exp \abs`.
- Неявное умножение, включая числа: `2 x`, `j 4`, `1.5 10^3`.
- Значения — `std::complex<double>`; действительные с Im = 0.
- Невычислимо → W001: значение не вычисляется, подстановка пропускается.

## 8. Inline-формулы (v1.3)

`$$…$$` внутри текста вычисляются по тем же правилам, что блоки:
- голое выражение → значение: `$$u/2$$` → `1`;
- присваивание → определяет переменную и рендерится как `x = rhs [= подстановка] = res`;
- `$$x =$$` → `x = значение`;
- `$$!…$$` → чистый LaTeX;
- единица `&…` работает;
- не определено → E005, рендерится как LaTeX без значения.

Строка целиком `$$имя$$` без пробелов — тоже inline (текстовый блок).

## 9. Ошибки

| Код | Значение |
|-----|----------|
| E001 | YAML (табы, отступы, структура) |
| E002 | незакрытый блок формулы |
| E005 | неопределённая переменная / inline |
| E007 | зарезервированное имя |
| W001 | невычислимо / пустая правая часть (warning) |

E003, E004, E006, E010 не используются (v1.3).

## 10. Подстановка и рендер блоков

`[ед.]` — единица серым после значения. Локальный `show_substitution`
переопределяет глобальный.

| Блок | show_substitution=true | false |
|---|---|---|
| `x = <нетривиальная rhs>` | `x = rhs = подстановка = res [ед.]` | `x = rhs = res [ед.]` |
| `x = <тривиальная rhs>` (число/переменная) | `x = rhs [ед.]` | `x = rhs [ед.]` |
| `x =` | `x = res [ед.]` | `x = res [ед.]` |
| голое выражение | `res [ед.]` | `res [ед.]` |
| `!…` | как написано [ед.] | как написано [ед.] |
| `hide` / `hide!` | не рендерится | не рендерится |

Подстановка — правая часть со значениями переменных на момент вычисления блока.
Формула с W001/E005 рендерится как есть, без подстановки и результата.

## 11. Таблицы

Строки `| a | b |`; вторая строка-разделитель `|---|:--:|---:|` задаёт
выравнивание колонок и делает первую строку шапкой. Без разделителя шапки нет.
Ячейки вычисляются по правилам §8. Таблица центрирована, границы чёрные.

## 12. Списки

`- ` — маркированный, `1. ` — нумерованный; вложенность — отступ 2 пробела,
до 3 уровней; смена типа на уровне переоткрывает список. Inline работает.

## 13. Картинки

`![подпись](имя.файла)` — файл из `images/` ZIP-проекта. Блок центрирован,
подпись под картинкой, блок не разрывается между страницами. Файла нет —
серый плейсхолдер `[image: имя]`.

## 14. Оглавление

`[toc]` — список заголовков с точечными лидерами и номерами страниц, ссылки
кликабельны. Заголовок, стоящий непосредственно перед `[toc]`, в список не
входит. Размер — `toc_size`.

## 15. Разрыв страницы и нумерация

- `[break]` / `[pagebreak]` — следующий блок с новой страницы.
- Нумерация страниц — только в PDF (требуется qpdf): номер внизу по центру
  в нижнем поле. Страницы нумеруются последовательно начиная с `page_start`;
  при `number_first_page: false` номер первой страницы не печатается.

## 16. Пример

```
---
title: Расчёт режима 110 кВ
show_substitution: true
page:
  margin:
    left: 3cm
align: justify
---
[break]
# Оглавление
[toc]

# Исходные данные

$$R_{line} = 10 &Ом$$
$$X_{line} = 50 &Ом$$
$$hide
S = 100 &МВА$$

# Сопротивление

$$Z_{line} = \sqrt{R_{line}^2 + X_{line}^2} &Ом$$
# многострочный блок с комментарием

Полное сопротивление: $$Z_{line}$$ Ом, ток $$I = S / Z_{line}$$ А.
$$! I_{pure} = \frac{S}{Z}$$ — чистый LaTeX, не считается.
```

## 17. Технические требования

- UTF-8.
- Перф: 1000 строк < 100 мс, 10000 < 1 с (parse + evaluate).
- Рантайм-зависимость для нумерации PDF: qpdf (Linux: пакет; Windows: рядом с exe).
- Сборка: Conan (yaml-cpp, gtest, zlib) + системный/инсталляторный Qt; Windows — windeployqt.
- Неизвестные YAML-ключи и будущие модификаторы — расширяемо без переписывания.
