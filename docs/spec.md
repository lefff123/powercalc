# Спецификация формата документа PowerCalc

**Версия:** 1.1
**Статус:** Финальная для v1 продукта

## 1. Обзор

Документ PowerCalc — текстовый файл `document.txt` (UTF-8) внутри ZIP-проекта.
Markdown-подобный синтаксис с блоками формул. Формулы вычисляются в порядке
появления, значения подставляются при рендере. Рендер — KaTeX (этап 2.3),
парсер/эвалюатор не зависят от рендера.

## 2. Блоки

| Тип | Синтаксис |
|-----|-----------|
| YAML | `---` … `---`, только первым блоком |
| Заголовок | `#` / `##` / `###` + пробел |
| Формула | `$$` … `$$` |
| Текст | всё остальное; пустые строки разделяют блоки |

## 3. YAML блок

- Парсится библиотекой yaml-cpp. Отступы — по стандарту YAML: **2 пробела**
  на уровень. Таб в отступах запрещён стандартом → ошибка E001 с номером строки.
- Ключи v1:

| Ключ | Тип | Дефолт |
|------|-----|--------|
| `title` | string | пусто |
| `author` | string | пусто |
| `date` | string | пусто |
| `show_substitution` | bool | `true` |
| `page.size` | string | `A4` |
| `page.margin.top/bottom/left/right` | length (cm/mm) | `2cm` |
| `align` | left/center/right/justify | `justify` (по ширине) |
| `text.size` | length (pt) | `14pt` |

- Шрифт не настраивается: Times New Roman зашит (смена шрифта — будущее).
- Короткой формы `margin: 2cm` нет — только полная форма по сторонам.
- Неизвестные ключи игнорируются и сохраняются при пересохранении.

## 4. Заголовки

`#`, `##`, `###` + обязательный пробел. `####` и более, `#` без пробела — текст.

## 5. Блок формулы

### 5.1 Открытие и закрытие (уточнено в 1.1)

- Открывается строкой, начинающейся с `$$`, далее опциональный модификатор,
  далее опционально контент на той же строке.
- Закрывается следующим `$$` где угодно: отдельная строка или хвост строки
  с контентом. Однострочные `$$…$$` — блок.
- Исключения (это НЕ блоки):
  - строка целиком `$$имя$$` — inline-формула (текст);
  - после закрывающего `$$` идёт текст — текст с inline.
- `$$hide $$` (после модификатора сразу закрытие) — блок, не inline.
- Незакрытый блок → E002.

### 5.2 Модификаторы

| Модификатор | Значение |
|-------------|----------|
| (нет) | обычная формула |
| `hide` | блок не рендерится, но вычисляется и попадает в SymbolTable |
| `!` | инверсия `show_substitution` для блока |
| `hide!` | комбинация |

Неизвестный модификатор → E003.

### 5.3 Единица измерения

Первый `&` в последней контент-строке; всё после — единица (любой текст:
`Ом`, `кВт·ч`, `руб/кВт·ч`). В вычислениях не участвует.

### 5.4 Комментарии

Внутри блока формулы `#` — комментарий до конца строки или до `$$`;
работает и в середине строки. В рендере не выводится.
Вне блока формулы `#` — заголовок или текст, не комментарий.

### 5.5 Склейка

Контент-строки (кроме комментариев) соединяются через пробел в одно выражение.

## 6. Переменные, индексы, имена

- Имя: начинается с буквы (лат/кириллица), далее буквы/цифры.
- Индекс: `_x` (один символ) или `_{...}`. Нормализация: `R_x` ≡ `R_{x}`.
  Вложенные индексы (`_{a_{b}}`) не поддерживаются → W001.
- Зарезервированы (определение → E007, включая индексные формы):
  `sqrt frac sin cos tan log ln exp abs pi e j`.
- Греческие `\alpha`, `\beta`… — переменные с именами `alpha`, `beta`…
- `\cdot`, `\times` — умножение; `\pm` → W001.
- `\log` — десятичный логарифм, `\ln` — натуральный.

## 7. Выражения и вычисление

- Формула обязана быть присваиванием (слева переменная), иначе E010.
  Пустая правая часть → W001.
- Вычисление строго в порядке появления. Неопределённая переменная → E005.
- Переопределение разрешено, побеждает последнее.
- **Ошибка вычисления → переменная не определяется/не переопределяется;
  старое значение продолжает жить.**
- Операции: `+ - * / ^`, скобки, числа с точкой `.`, `j` — мнимая единица,
  `pi`, `e` — константы; функции: `\sqrt \frac \sin \cos \tan \log \ln \exp \abs`.
- **Неявное умножение**, включая числа: `2 x` = 2·x, `j 4` = j·4, `x 2` = x·2.
  Внимание: `2 3` = 6, `1.5 10^3` = 1500.
- Значения — `std::complex<double>`; действительные — с Im = 0.
- Невычислимо (деление на ноль, неизвестная команда `\int` и т.п.) → W001:
  значение не вычисляется, подстановка пропускается, документ не блокируется.

## 8. Inline-формулы

`$$имя$$` внутри текста (в т.ч. строка целиком) — значение переменной.
Не определена → E005 с номером строки. В рендере не определёна → `??`.

## 9. Ошибки

Парсер собирает все ошибки за один проход; каждая: код, строка, текст.

| Код | Значение |
|-----|----------|
| E001 | YAML (табы, отступы, структура) |
| E002 | незакрытый блок формулы |
| E003 | неизвестный модификатор |
| E005 | неопределённая переменная / inline |
| E007 | зарезервированное имя |
| E010 | не присваивание |
| W001 | невычислимо (warning, не блокирует) |

E004, E006 не используются.

## 10. Подстановка и рендер

Поведение блока:

| show_substitution | `!` | Рендер |
|---|---|---|
| true | нет | формула = подстановка = результат [ед.] |
| true | да | формула = результат [ед.] |
| false | нет | формула = результат [ед.] |
| false | да | формула = подстановка = результат [ед.] |

- **Подстановка** — правая часть формулы с значениями переменных на момент
  вычисления этого блока:
  `Z = \sqrt{R^2 + X^2} = \sqrt{10^2 + 50^2} = 50.99 Ом`.
- `hide` не рендерится никогда, независимо от `!`.
- Формула с W001/E005/E010 рендерится как есть, без подстановки и результата.
- Комментарии не рендерятся. Единица — после результата, серым.
- YAML-мета управляет страницей рендера: поля (`@page`), выравнивание текста,
  размер шрифта; шрифт — Times New Roman.

## 11. Пример

---
title: Расчёт режима 110 кВ
show_substitution: true
page:
  margin:
    left: 3cm
align: justify
---

# Исходные данные

$$R_{line} = 10 &Ом$$
$$X_{line} = 50 &Ом$$

# Сопротивление

$$Z_{line} = \sqrt{R_{line}^2 + X_{line}^2} &Ом$$
# многострочный блок с комментарием

Полное сопротивление: $$Z_{line}$$ Ом.

## 12. Технические требования

- UTF-8.
- Перф: 1000 строк < 100 мс, 10000 < 1 с (parse + evaluate).
- Неизвестные YAML-ключи и будущие модификаторы — расширяемо без переписывания.
